令牌

{{if .Me}}

令牌存在名为 fastoj_token 的 HttpOnly + SameSite=Lax Cookie 里， 网页提交用的就是它；纯文本 API 仍走 Authorization: Bearer。

{{else}}

把管理员为你签发的 API 令牌粘到这里，之后网页提交与 curl 用的是同一枚令牌。

{{end}}

命令行用法

curl -s -H "Authorization: Bearer $TOKEN" localhost:8080/whoami
curl -s -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"problem":"P1001","language":"cpp","source":"int main(){}"}' localhost:8080/submissions
curl -s -H "Authorization: Bearer $TOKEN" "localhost:8080/submissions/1?wait=30"
{{end}}
